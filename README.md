# MLENG FIAP

Este repositório foi criado para as aulas da pós-graduação em Machine Learning Engineering na FIAP.

## Estrutura do Projeto

### Fase 1

[![Acessar Documentação da Fase 1](https://img.shields.io/badge/Acessar_Documenta%C3%A7%C3%A3o-Fase_1-0052cc?style=for-the-badge)](./fase_1/README.md)

O objetivo desta fase é consolidar fundamentos essenciais para projetos de Machine Learning Engineering:
- Fundamentos de Machine Learning
- Fundamentos de Software
- Construção e integração de API
- Entendimento do negócio

### Fase 2

[![Acessar Documentação da Fase 2](https://img.shields.io/badge/Acessar_Documenta%C3%A7%C3%A3o-Fase_2-0052cc?style=for-the-badge)](./fase_2/README.md)

**Tech Challenge Fase 02 - Sistema de Recomendação de E-commerce**

Este projeto implementa um sistema de recomendação de e-commerce utilizando técnicas de aprendizado profundo e aprendizado de máquina tradicional. A arquitetura é baseada em pipelines DVC para orquestrar o fluxo de pré-processamento, treinamento e avaliação.

### Fase 3

[![Acessar Documentação da Fase 3](https://img.shields.io/badge/Acessar_Documenta%C3%A7%C3%A3o-Fase_3-0052cc?style=for-the-badge)](./fase_3/README.md)

**Tech Challenge Fase 03 - Deploy de Modelo em Produção**

Este projeto implementa uma solução completa de MLOps para triagem automática de laudos médicos. Cobre as etapas de ingestão, validação, treinamento, orquestração com Airflow e otimização de latência com ONNX Runtime, incluindo CI/CD e monitoramento.
