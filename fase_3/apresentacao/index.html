A ACTION — CI/CD

Pipeline Automatizado

  • 🔍 Lint (Ruff): Verificação de qualidade de código a cada push para manter padrões de codificação.
  • 🧪 Testes (Pytest): Suíte de testes automatizados para validar modelos, API e utilitários.
  • 🔒 Merge Validation: Workflow dedicado para validação em Pull Requests antes do merge.
  • 📦 Build: Construção do container Docker com o modelo otimizado pronto para deploy.
# .github/workflows/ci.yml

name: CI Pipeline
on: [push, pull_request]

jobs:
  lint:
    run: ruff check .

  test:
    run: pytest

  build:
    run: docker build .
